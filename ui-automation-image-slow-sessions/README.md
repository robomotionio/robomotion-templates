# Slow sessions

A flow recorded on a good Remote Desktop session that logs on and updates a customer's email, phone and notes in Acme ERP, and still gets every value right on a slow session that loses keystrokes.

The finished flow of the Robomotion Academy lesson **Slow sessions** (UI Automation course).

## Before you run it

- The Acme training apps in `C:\Acme`: `AcmeERP-Windows`, `AcmeERP-Java` and `AcmeRemote`, as the course's download unpacks them.
- Input files in `C:\Acme\in`; the flow writes its files to `C:\Acme\out`.
- The training sign-in is in the flow as plain text. In a flow of your own, read it from a vault.
